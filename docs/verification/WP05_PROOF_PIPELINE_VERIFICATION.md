## 5. Appropriateness evaluation

P5 belongs after environment compatibility because it verifies actual behavior of a concrete remote endpoint under the environment identity carried from P4.

The control-plane TCP oracle is more appropriate than granting proof authority to unrestricted Actor networking. Endpoint configuration is operator/admission sourced, hostname resolution is performed once, numeric addresses are pinned, and the observed response is compared against an operator-fixed digest. The resulting proof therefore binds one payload, one endpoint configuration, one observed response and one remote environment.

P5 uses Core `EXECUTION` strength because a network interaction actually occurred. This does not promote it to final success; only the task-native external flag/proof oracle can produce P6.
